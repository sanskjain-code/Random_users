# Random User Fetcher

A simple Python script that fetches random user data (username and country) from the [FreeAPI](https://api.freeapi.app) public endpoint.

## 🚀 Features
- Fetches random user details using `requests`
- Prints username and country in a clean format
- Handles errors gracefully

## 📦 Installation
Clone the repository and install dependencies:

```bash
git clone <your-repo-url>
cd random-user-fetcher
pip install -r requirements.txt
